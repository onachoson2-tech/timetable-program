# timetable-program
CKU(가톨릭관동대학교) AI소프트웨어융합학부 1학년 대상 대학 시간표 최적화 프로그램

GitHub: https://github.com/onachoson2-tech/timetable-program

---

## 프로젝트 개요

가톨릭관동대학교 AI소프트웨어융합학부 1학년 학생이 수강 조건을 설정하면
충돌 없는 최적 시간표 3개를 자동으로 생성해주는 데스크톱 앱입니다.

---

## 현재 상태

- 기본 구동 완료
- 버그 수정 및 코드 개선 진행 중
- data.csv 실데이터 입력 진행 중

## 2026학년도 교양 이수체계 (AI소프트웨어융합학부 1학년 기준)

> 출처: 가톨릭관동대학교 VERUM교양대학 공식 교육과정 (20~22학번 기준 적용)
> 총 이수 필요: 36학점

### 교양필수

| 영역 | 과목 | 학점 | 비고 |
|------|------|------|------|

| 인성 | 봉사와실천1, 2 | 2 | P/NP |
| 인성 | VERUM캠프1, 2 | 2 | P/NP |

### 2026학년도 주요 변경사항

## data.csv 컬럼 설명

| 컬럼명 | 설명 | 예시 |
|--------|------|------|
| 과목명 | 강의 이름 | 프로그래밍기초 |
| 교수 | 담당 교수 이름 | 주해종 |
| 요일 | 강의 요일 | 월, 화, 수, 목, 금 |
| 시작 | 강의 시작 시간 (HH:MM) | 09:00 |
| 종료 | 강의 종료 시간 (HH:MM) | 10:50 |
| 강의실 | 강의실 위치 | 가브리엘319 |
| 학점 | 이수 학점 수 | 2, 3, 0.5 |
| 카테고리 | 이수구분 | 전공필수, 전공선택, 교양필수, 교양선택 |
| 학년 | 수강 대상 학년 | 1, 2, 3, 4 |

### 카테고리 분류 기준

| 카테고리 값 | 해당 과목 유형 |
|-------------|----------------|
| 전공필수 | 전필 — 반드시 이수해야 하는 전공 과목 |
| 전공선택 | 전선 — 선택 이수 전공 과목 |
| 교양필수 | 교양 필수 이수 과목 (인성, 학문도구 영역 등) |
| 교양선택 | 교양 자유 선택 과목 (계열기초, 인문, 균형 영역 등) |

### 강의실 건물 약칭

| 약칭 | 건물명 |
|------|--------|
| 마리아 | 마리아관 |
| 바오로 | 바오로관 |
| 미카엘 | 미카엘관 |
| 가브리엘 | 가브리엘관 |
| 라파엘 | 라파엘관 |
| 대건 | 대건관 |
| 하상 | 하상관 |
| 창조 | 창조관 |
| 진실 | 진실관 |
| 스포츠센터 | 세바스티아노 스포츠센터 |

> 표기법: 건물약칭 + 호수 (예: 가브리엘319 = 가브리엘관 319호)

```
timetable_optimizer/
├── main.py          # 앱 진입점 및 이벤트 연결
├── ui_panel.py      # 왼쪽 설정 패널 UI

```
