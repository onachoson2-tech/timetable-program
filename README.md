# timetable-program
CKU(가톨릭관동대학교) AI소프트웨어융합학부 1학년 대상 대학 시간표 최적화 프로그램

GitHub: https://github.com/onachoson2-tech/timetable-program

---

## 프로젝트 개요

가톨릭관동대학교 AI소프트웨어융합학부 1학년 학생이 수강 조건을 설정하면
충돌 없는 최적 시간표 3개를 자동으로 생성해주는 데스크톱 앱입니다.

## 2026학년도 교양 이수체계 (AI소프트웨어융합학부 26학번 1학년 기준)

> 출처: 가톨릭관동대학교 VERUM교양대학 공식 교육과정 (2026학년도)
> 교양 총 이수: 28학점 이상

### 교양필수 (12학점)

| 대표역량 | 영역 | 과목 수 | 학점 | 비고 |
|------|------|------|------|------|
| 공동체 | VERUM인성:그리스도교문화 | 1과목 | 2 | 선택 이수 |
| 공동체 | VERUM인간 | **2과목** | 4 | 필수 이수 |
| 소통·공감 | 디지털소통 | **2과목** | 4 | 필수 이수 |
| 소통·공감 | 디지털시대의사고와표현 | 1과목 | 2 | 선택 이수 |

### 교양선택 (16학점)

진로탐색, 창의성, 창업, 정치와경제, 심리와건강, 정보와기술,
인간과문학, 역사와사회, 철학과예술, 자연과환경, 수리와과학, 언어와문화
주제 및 교과목에서 자유롭게 16학점 이수

### 2026학번 주요 변경사항

- 봉사와실천, VERUM캠프, VERUM인성(1학점) 해당 없음
- VERUM인성:그리스도교문화 신설 (2학점, 26학번 전용)
- 교양 교육과정은 한 학기에 전부 이수 불가 — 졸업 전까지 분산 이수

## 파일 구조

```
timetable_optimizer_fixed_1/
├── main.py          # 앱 진입점, 이벤트 연결, 학점 경고 검사
├── ui_panel.py      # 왼쪽 설정 패널 UI (트랙별 자동 체크 포함)
├── canvas_view.py   # 시간표 캔버스 그리기 (과목명·교수명·강의실 표시)

├── filters.py       # 시간표 조건 필터링 (학년·비고·오전회피·금공강·점심확보)
├── data_loader.py   # 데이터 로딩 및 시간 처리 (26학번 수강 자격 사전 필터링)
├── config.py        # 상수 및 규칙 정의
```
